Agente incorporado em tempo real em hardware embarcado Real-time embodied agent on embedded hardware

projeto com empresa parceiraindustry-partnered project

Construí um agente que combina percepção facial contínua (detecção, identificação e expressão) com geração periódica de um modelo pequeno de visão e linguagem (sVLM), tudo no mesmo acelerador embarcado. Caracterizei a disputa de GPU entre percepção e geração e entreguei um harness de benchmark reprodutível. I built an agent that combines continuous face perception (detection, identification and expression) with periodic generation from a small vision-language model (sVLM), all on the same embedded accelerator. I characterized GPU contention between perception and generation and delivered a reproducible benchmark harness.

Léxico de misoginia em PT-BR PT-BR misogyny lexicon

NLP · open source

Unifiquei 3 corpora anotados e dedupliquei de 74.338 para 35.791 documentos. Construí um léxico de 533 termos (TF-IDF + PMI) e um filtro de ancoragem de gênero que reduziu os termos positivos de 267 para 111. Comparei SVM, regressão logística, random forest e MLP. I merged 3 annotated corpora and deduplicated them from 74,338 to 35,791 documents. I built a 533-term lexicon (TF-IDF + PMI) and a gender-anchoring filter that cut positive terms from 267 to 111. I compared SVM, logistic regression, random forest and MLP.

F1 0,748 vs 0,730 do baseline · achei e corrigi um vazamento de dados que inflava o F1 para 0,87 F1 0.748 vs 0.730 baseline · found and fixed a data leak that inflated F1 to 0.87
